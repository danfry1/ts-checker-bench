How long does a full TypeScript type check take?

5 type checkers on 3 real projects, each a fresh process with no incremental cache, on one Apple M5 in one session. Every figure links to the raw output behind it.

Full checks only: not watch mode, editors or --build. One machine. Independent: not affiliated with or funded by Microsoft, Vercel, Oven (bun) or the authors of any checker here.

Threads
Default: each checker as it ships.

Default threading differs: tsgo and tsc-rs default to 4 checkers; tsc-ts, tsrs and bun use one per core, up to 10 on this 10-core machine (sources). The other settings give every checker the same thread count, set with its documented flag. ¹ marks a checker that reported errors where tsgo reported none.

Do they report the same errors?

Each checker ran every project clean and with a few planted type errors, and its output was compared with tsgo's.

  • tsc-ts
    Identical to tsgo

    Byte-for-byte the same output as tsgo on all 3 projects, clean and with planted errors.

  • tsc-rs
    Same as the TypeScript build it ports

    Reports errors tsgo 7.0.2 does not: 10 on VS Code and 1 on Outline. One message prints a type differently on type-fest. Upstream tsgo built from the TypeScript commit it ports, typescript@7.1.0-dev.20261008.1, prints exactly the same output on every project, so these differences come from that TypeScript version, not from tsc-rs.

  • tsrs
    Same as the TypeScript build it ports

    Reports errors tsgo 7.0.2 does not: 10 on VS Code and 1 on Outline. One message prints a type differently on type-fest. Upstream tsgo built from the TypeScript commit it ports, typescript@7.1.0-dev.20260930.4, prints exactly the same output on every project, so these differences come from that TypeScript version, not from tsrs.

  • bun
    Same errors as tsgo

    Prints tsgo's error lines word for word on all 3 projects, and adds its own summary of the check.

Checkers

  • tsgoreference
    typescript@7.0.2

    Microsoft's native TypeScript 7 compiler (Go).

    Default threading: 4 checkers. Thread flags used: --singleThreaded and --checkers N.

  • tsc-ts
    tsc-ts@0.0.3

    A TypeScript port of tsgo 7.0.2, compiled to a native executable with scriptc (Vercel Labs).

    Default threading: one per core (10 here). Thread flags used: --singleThreaded and --checkers N.

  • tsc-rs
    tsc-rs@0.7.0

    A Rust port of the TypeScript 7 compiler (pingdotgg/ts-rust).

    Default threading: 4 checkers. Thread flags used: --singleThreaded and --checkers N.

  • tsrs
    tsrs@0.16.0-ts7.1.0-dev.20260929

    A Rust port of the TypeScript 7 compiler (oxc-project).

    Default threading: one per core (10 here). Thread flags used: --singleThreaded and --checkers N.

  • bun
    bun@1.4.3

    Bun's built-in type checker (bun check).

    Default threading: one per core (10 here). Thread flags used: --threads=1 and --threads=N.

Diagnostics only, never timed: upstream tsgo typescript@7.1.0-dev.20260930.4, the build tsrs ports; typescript@7.1.0-dev.20261008.1, the build tsc-rs ports.

Thread defaults and flags as each checker documents them (sources). Each binary's version output and sha256 are in run.json.

How it was measured

Machine
Apple M5, 10 cores, 24 GiB, macOS 26.5.1 (25F80)
Each measurement
A fresh process with no incremental cache or build info. The OS file cache is warm for every checker alike: each set of runs starts with a warm-up round.
Rounds
7 timed rounds after 1 warm-up; the figure shown is the median. Checker order within each round: rotated, each round starting one place further along.
Settings
Each checker's shipped defaults plus the project's own typecheck arguments. No tuning flags.
Projects
Pinned to a commit, installed from their own lockfiles. A project is benchmarked only if tsgo reports 0 errors on it; rejected in this run: excalidraw.
Conditions
All 570 timed runs on AC power, kept awake by caffeinate. Sleep, wake and thermal events: none. Preflight warnings: none.
Harness
bde799c06fc9 (added 2026-10-19: this run did not record it; the last harness commit before the run started and the parent of its results commit 11c0091, which changes no harness file)

Caveats, and what the numbers do not show, in docs/METHOD.md. Every file behind this page is in results/2026-10-19-apple-m5-darwin/, with its full report.

Run it yourself

On macOS, Linux or Windows, with Node 22.18 or later and git, on a quiet machine on AC power. A full run takes about an hour on a 10-core Mac. AGENTS.md has every prerequisite and step.

git clone https://github.com/danfry1/ts-checker-bench
cd ts-checker-bench
(cd bench && npm ci && npm run check)
# every checker and project, about 10 GB
node bench setup
# plugged in? anything busy?
node bench preflight
# writes results/<date>-<cpu>-<os>/
node bench run
